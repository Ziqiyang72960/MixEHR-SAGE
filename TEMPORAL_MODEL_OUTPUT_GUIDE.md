# Temporal Markov Chain Model - Output Guide

This guide explains the output files generated by the temporal topic model and how to interpret them.

## What is Temporal Topic Modeling?

### Overview
The temporal topic model tracks how disease patterns (topics) evolve over time for individual patients. Instead of treating all patient data as a single snapshot, it captures the **dynamic progression** of diseases across multiple visits.

### Key Concepts

**Topics**: Groups of related medical codes that tend to occur together (e.g., "cardiovascular disease" topic might include codes for hypertension, heart failure, and cardiac medications)

**Theta (θ)**: The probability distribution over topics for a patient at a specific time point. Each patient has a different θ at each visit, showing how their disease profile changes over time.

**Time Steps**: Sequential visits or time periods. Time step 0 = first visit, time step 1 = second visit, etc.

**Markov Chain**: Each visit's topic distribution depends on the previous visit's distribution, modeling disease progression as a chain of related states.

## What Can You Infer from Temporal Data?

### 1. Disease Progression Patterns
**What it shows**: How a patient's disease profile changes over time

**Example inferences**:
- "Patient started with diabetes-related codes (topic 5) at time 0, developed cardiovascular complications (topic 12) by time 3"
- "Patient's respiratory disease topic probability increased from 0.1 to 0.6 over 4 visits"
- "Identify patients who transitioned from metabolic syndrome to cardiovascular disease"

**How to analyze**: Compare theta distributions across time steps for the same patient

### 2. Treatment Response
**What it shows**: Changes in disease burden after interventions

**Example inferences**:
- "After starting medication at visit 2, inflammatory disease topic (topic 8) probability decreased"
- "Patient's acute care topics peaked at visit 1 (hospitalization) then declined"
- "Identify which patients responded well to treatment (topic probability decreases)"

**How to analyze**: Look for decreases in disease-related topic probabilities after treatment start dates

### 3. Risk Prediction
**What it shows**: Topic trajectories that predict future complications

**Example inferences**:
- "Patients whose diabetes topic increases above 0.7 have 80% chance of complications"
- "Rising cardiovascular topic probability predicts hospital admission within 6 months"
- "Topic transition patterns (5→12→18) associated with poor outcomes"

**How to analyze**: Train predictive models using topic sequences as features

### 4. Comorbidity Development
**What it shows**: How multiple diseases interact and develop together

**Example inferences**:
- "Patients with high respiratory topic often develop cardiovascular topics within 2 years"
- "Metabolic and mental health topics frequently co-occur and increase together"
- "Identify common disease progression pathways in the population"

**How to analyze**: Look for correlations between different topics appearing or increasing together

### 5. Patient Phenotyping
**What it shows**: Groups of patients with similar disease trajectories

**Example inferences**:
- "Cluster A: rapid progression from healthy to multi-morbid (topics 1→5→12→18)"
- "Cluster B: stable chronic disease management (topic 7 remains dominant)"
- "Identify 'fast progressors' vs 'slow progressors' based on topic evolution speed"

**How to analyze**: Cluster patients based on their theta_temporal sequences

### 6. Temporal Clinical Insights
**What it shows**: Time-dependent patterns in disease management

**Example inferences**:
- "Average time between diabetes diagnosis (topic 5 appears) and complications (topic 12 appears) is 3.5 visits"
- "Seasonal patterns: respiratory topics peak in winter months"
- "Medication compliance: topic probabilities stabilize when medication topics are consistent"

**How to analyze**: Aggregate statistics across patients' temporal patterns

## Output Files

When you run `train_temporal.py`, the following files are created in the output directory (default: `./results/`):

### 1. `vocabularies.pkl` - Medical Code Mappings
**Purpose**: Maps between string medical codes (e.g., "J45", "E11.9") and integer IDs used internally.

**What it represents**:
- **Code dictionary**: All unique medical codes found in your data, organized by modality (ICD, medications, procedures)
- **Integer encoding**: Each code gets a unique number for efficient computation
- **Bidirectional mapping**: Can translate from code to ID or ID to code

**What you can infer**:
1. **Vocabulary size**: How many unique codes appear in each modality
2. **Code coverage**: Which specific codes are represented in your dataset
3. **Data completeness**: Missing codes indicate data gaps
4. **Modality distribution**: Relative sizes tell you data richness per modality

**Contents**:
```python
{
    'code_to_id': {
        modality_id: {code_string: integer_id},  # e.g., {0: {"J45": 0, "E11.9": 1, ...}}
        ...
    },
    'id_to_code': {
        modality_id: {integer_id: code_string},  # e.g., {0: {0: "J45", 1: "E11.9", ...}}
        ...
    },
    'vocab_sizes': [vocab_size_mod0, vocab_size_mod1, ...],
    'modality_names': ['icd', 'medication', 'opcs']
}
```

**Usage Example**:
```python
import pickle

# Load vocabularies
vocab = pickle.load(open('results/vocabularies.pkl', 'rb'))

# Get the medical code for integer ID 5 in modality 0 (ICD)
code = vocab['id_to_code'][0][5]
print(f"Word ID 5 in ICD modality corresponds to code: {code}")

# Get the integer ID for code "J45" in modality 0 (ICD)
word_id = vocab['code_to_id'][0]["J45"]
print(f"ICD code J45 has integer ID: {word_id}")
```

### 2. `patient_id_mapping.pkl` - Patient ID to Array Index
**Purpose**: Maps between patient IDs (e.g., 1001, 1002) and array indices (0, 1, 2, ...) used in `theta_temporal`.

**What it represents**:
- **Index mapping**: Technical mapping required because numpy arrays use 0-based sequential indices
- **Patient identifiers**: Your original patient IDs from the CSV files (can be any format)
- **Bidirectional lookup**: Can go from patient ID to array position or vice versa

**What you can infer**:
- This is purely a technical mapping file - no clinical insights
- Essential for accessing the correct row in theta_temporal for a given patient
- Useful for matching model outputs back to your original patient database

**Contents**:
```python
{
    'patient_id_to_idx': {patient_id: array_index},  # e.g., {1001: 0, 1002: 1, ...}
    'idx_to_patient_id': {array_index: patient_id},  # e.g., {0: 1001, 1: 1002, ...}
    'description': 'Mapping between patient IDs and array indices used in theta_temporal'
}
```

**Usage Example**:
```python
# Load mapping
mapping = pickle.load(open('results/patient_id_mapping.pkl', 'rb'))

# Get array index for patient 1001
idx = mapping['patient_id_to_idx'][1001]
print(f"Patient 1001 is at array index: {idx}")

# Get patient ID for array index 0
patient_id = mapping['idx_to_patient_id'][0]
print(f"Array index 0 corresponds to patient: {patient_id}")
```

### 3. `patient_sequences.pkl` - Visit Sequences
**Purpose**: Contains the temporal sequence of visits for each patient with medical codes.

**What it represents**:
- **Visit history**: Complete record of what medical codes appeared at each patient visit
- **Temporal ordering**: Visits are in chronological order
- **Multi-modal data**: Includes ICD diagnosis codes, medications, and procedures all aligned by time
- **Word IDs**: Medical codes are represented as integers (use vocabularies.pkl to decode)

**What you can infer**:
1. **Treatment patterns**: What medications were prescribed at different disease stages
2. **Intervention timing**: When procedures were performed relative to diagnoses
3. **Code co-occurrence**: Which conditions and treatments appear together
4. **Care intensity**: Number and diversity of codes per visit
5. **Diagnostic evolution**: New diagnoses appearing over time
6. **Medication changes**: Additions, removals, or substitutions of medications

**Contents**:
```python
{
    'patient_sequences': {
        patient_id: [
            {
                'time': datetime or visit_index,
                'words': {
                    modality_id: {word_id: frequency},  # word_id is integer, use vocabularies.pkl to decode
                    ...
                }
            },
            ...  # One entry per visit
        ],
        ...
    },
    'patient_metadata': {
        patient_id: {
            'num_visits': int,
            'first_visit': datetime,
            'last_visit': datetime
        },
        ...
    }
}
```

**Usage Example**:
```python
# Load sequences and vocabularies
sequences = pickle.load(open('results/patient_sequences.pkl', 'rb'))
vocab = pickle.load(open('results/vocabularies.pkl', 'rb'))

# Get visits for patient 1001
patient_visits = sequences['patient_sequences'][1001]

# Decode codes for first visit
first_visit = patient_visits[0]
print(f"Visit time: {first_visit['time']}")

for modality_id, word_freq in first_visit['words'].items():
    print(f"\nModality {modality_id} ({vocab['modality_names'][modality_id]}):")
    for word_id, freq in word_freq.items():
        code = vocab['id_to_code'][modality_id][word_id]
        print(f"  {code}: {freq} occurrences")
```

### 4. `theta_results.pkl` - Topic Distributions Over Time
**Purpose**: Contains the inferred topic distributions (theta) for each patient at each time step.

**What it represents**:
- **Theta (θ_temporal)**: A 3D array where each value represents the probability that a patient has a particular disease/condition topic active at a specific time
- **Dimensions**: (patients, time_steps, topics)
  - **Patient dimension**: Each row corresponds to one patient
  - **Time dimension**: Each column is a sequential visit (0=first visit, 1=second visit, etc.)
  - **Topic dimension**: Each topic represents a group of related medical conditions
- **Interpretation**: `theta[patient_idx, time, topic_k] = 0.3` means "at this visit, 30% of this patient's disease burden is explained by topic k"

**What you can infer**:
1. **Current disease state**: Which topics (disease groups) are currently active for a patient
2. **Disease progression**: How topic probabilities change from visit to visit
3. **Dominant conditions**: Which topic has the highest probability at each time point
4. **Multi-morbidity**: Patients with many topics having significant probabilities
5. **Treatment effects**: Decreasing probabilities after interventions
6. **Trajectory patterns**: Sequences of dominant topics revealing disease pathways

**Contents**:
```python
{
    'theta_temporal': numpy.ndarray,  # Shape: (num_patients, num_time_steps, num_topics)
    'patient_time_mask': numpy.ndarray,  # Shape: (num_patients, num_time_steps)
    'patient_id_to_idx': dict,  # Same as in patient_id_mapping.pkl
    'idx_to_patient_id': dict,
    'num_topics': int,
    'num_time_steps': int,
    'description': {
        'theta_temporal': 'Topic distributions over time...',
        'patient_time_mask': 'Binary mask indicating which time steps have data...',
        'usage': 'To get theta for patient_id at time t: theta_temporal[patient_id_to_idx[patient_id], t, :]'
    }
}
```

**Usage Example**:
```python
import numpy as np

# Load theta results
theta_results = pickle.load(open('results/theta_results.pkl', 'rb'))

# Get topic distribution for patient 1001 at time step 2
patient_id = 1001
time_step = 2

idx = theta_results['patient_id_to_idx'][patient_id]
theta = theta_results['theta_temporal'][idx, time_step, :]

# Check if this time step has data
has_data = theta_results['patient_time_mask'][idx, time_step]

if has_data:
    print(f"Patient {patient_id} at time {time_step}:")
    print(f"Topic distribution: {theta}")
    
    # Find dominant topics
    top_topics = np.argsort(theta)[-5:][::-1]  # Top 5 topics
    print(f"Top 5 topics: {top_topics}")
    print(f"Their probabilities: {theta[top_topics]}")
else:
    print(f"No data for patient {patient_id} at time {time_step}")
```

## Complete Example: Analyzing a Patient's Disease Progression

```python
import pickle
import numpy as np

# Load all necessary files
vocab = pickle.load(open('results/vocabularies.pkl', 'rb'))
sequences = pickle.load(open('results/patient_sequences.pkl', 'rb'))
theta_results = pickle.load(open('results/theta_results.pkl', 'rb'))

patient_id = 1001

# 1. Get patient metadata
metadata = sequences['patient_metadata'][patient_id]
print(f"Patient {patient_id}:")
print(f"  Number of visits: {metadata['num_visits']}")
print(f"  First visit: {metadata['first_visit']}")
print(f"  Last visit: {metadata['last_visit']}")

# 2. Get patient's visit history
visits = sequences['patient_sequences'][patient_id]
print(f"\n=== Visit History ===")
for i, visit in enumerate(visits):
    print(f"\nVisit {i} at {visit['time']}:")
    for mod_id, word_freq in visit['words'].items():
        mod_name = vocab['modality_names'][mod_id]
        print(f"  {mod_name}:")
        for word_id, freq in word_freq.items():
            code = vocab['id_to_code'][mod_id][word_id]
            print(f"    {code} (×{freq})")

# 3. Get topic distributions over time
idx = theta_results['patient_id_to_idx'][patient_id]
num_time_steps = theta_results['num_time_steps']

print(f"\n=== Topic Distribution Over Time ===")
for t in range(num_time_steps):
    if theta_results['patient_time_mask'][idx, t]:
        theta = theta_results['theta_temporal'][idx, t, :]
        dominant_topic = np.argmax(theta)
        print(f"Time {t}: Dominant topic = {dominant_topic} (prob={theta[dominant_topic]:.3f})")
```

## Practical Analysis Examples

### Example 1: Identify Disease Progression Patterns

```python
import pickle
import numpy as np

# Load data
theta_results = pickle.load(open('results/theta_results.pkl', 'rb'))
mapping = pickle.load(open('results/patient_id_mapping.pkl', 'rb'))

def analyze_progression(patient_id):
    """Analyze how a patient's disease profile changes over time"""
    idx = theta_results['patient_id_to_idx'][patient_id]
    theta = theta_results['theta_temporal'][idx]
    mask = theta_results['patient_time_mask'][idx]
    
    print(f"Patient {patient_id} Disease Progression:")
    
    for t in range(len(mask)):
        if mask[t]:
            # Get top 3 topics at this time
            top_k = 3
            top_topics = np.argsort(theta[t])[-top_k:][::-1]
            
            print(f"\nVisit {t}:")
            for rank, topic in enumerate(top_topics):
                prob = theta[t, topic]
                print(f"  #{rank+1}: Topic {topic} ({prob:.3f})")
            
            # Check if dominant topic changed
            if t > 0 and mask[t-1]:
                prev_dominant = np.argmax(theta[t-1])
                curr_dominant = np.argmax(theta[t])
                if prev_dominant != curr_dominant:
                    print(f"  ⚠ Topic shift: {prev_dominant} → {curr_dominant}")

# Analyze specific patient
analyze_progression(1001)
```

**What this reveals**: 
- Topic stability vs. volatility
- Major disease transitions
- Chronic vs. acute conditions
- Treatment efficacy (if topic probabilities decrease)

### Example 2: Compare Topic Evolution Across Patients

```python
import pickle
import numpy as np
import matplotlib.pyplot as plt

# Load data
theta_results = pickle.load(open('results/theta_results.pkl', 'rb'))

def compare_patients(patient_ids, topic_of_interest):

### Example 3: Predict Future Risk

```python
import pickle
import numpy as np

# Load data
theta_results = pickle.load(open('results/theta_results.pkl', 'rb'))
sequences = pickle.load(open('results/patient_sequences.pkl', 'rb'))

def calculate_risk_score(patient_id, risk_topics=[12, 15, 18]):
    """
    Calculate cumulative risk score based on high-risk topics
    risk_topics: list of topic IDs associated with adverse outcomes
    """
    idx = theta_results['patient_id_to_idx'][patient_id]
    theta = theta_results['theta_temporal'][idx]
    mask = theta_results['patient_time_mask'][idx]
    
    risk_scores = []
    
    for t in range(len(mask)):
        if mask[t]:
            # Sum probabilities of risk topics
            risk = sum(theta[t, topic] for topic in risk_topics)
            risk_scores.append(risk)
    
    # Calculate trend
    if len(risk_scores) >= 2:
        trend = risk_scores[-1] - risk_scores[0]
        increasing = trend > 0.1  # 10% increase
    else:
        increasing = False
    
    current_risk = risk_scores[-1] if risk_scores else 0
    
    print(f"Patient {patient_id} Risk Assessment:")
    print(f"  Current risk score: {current_risk:.3f}")
    print(f"  Risk trajectory: {'INCREASING ⚠' if increasing else 'Stable'}")
    print(f"  Risk over time: {[f'{r:.2f}' for r in risk_scores]}")
    
    return {
        'current_risk': current_risk,
        'increasing': increasing,
        'history': risk_scores
    }

# Assess risk for a patient
risk_assessment = calculate_risk_score(1001, risk_topics=[12, 15, 18])

# Flag high-risk patients
if risk_assessment['current_risk'] > 0.5 and risk_assessment['increasing']:
    print("\n🚨 HIGH RISK: Consider intervention")
```

**What this reveals**:
- Patients at high risk for complications
- Early warning signals
- Candidates for preventive interventions
- Resource allocation priorities

### Example 4: Discover Common Disease Pathways

```python
import pickle
import numpy as np
from collections import Counter

# Load data
theta_results = pickle.load(open('results/theta_results.pkl', 'rb'))

def find_topic_sequences():
    """Identify common sequences of dominant topics across all patients"""
    
    all_sequences = []
    
    # Extract dominant topic sequence for each patient
    for patient_id, idx in theta_results['patient_id_to_idx'].items():
        theta = theta_results['theta_temporal'][idx]
        mask = theta_results['patient_time_mask'][idx]
        
        sequence = []
        for t in range(len(mask)):
            if mask[t]:
                dominant = np.argmax(theta[t])
                sequence.append(dominant)
        
        if len(sequence) >= 3:  # Only consider sequences of 3+ visits
            all_sequences.append(tuple(sequence))
    
    # Find most common sequences
    sequence_counts = Counter(all_sequences)
    
    print("Most Common Disease Progression Pathways:")
    for seq, count in sequence_counts.most_common(10):
        print(f"  {' → '.join(map(str, seq))}: {count} patients")
    
    return sequence_counts

pathways = find_topic_sequences()
```

**What this reveals**:
- Typical disease progression patterns in the population
- Common comorbidity sequences
- Expected vs. unexpected disease trajectories
- Clinical pathways for quality improvement

### Example 5: Temporal Clustering of Patients

```python
import pickle
import numpy as np
from sklearn.cluster import KMeans
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

# Load data
theta_results = pickle.load(open('results/theta_results.pkl', 'rb'))

def cluster_patient_trajectories(n_clusters=3):
    """Cluster patients based on their temporal topic evolution"""
    
    # Flatten theta_temporal to (patients, time_steps * topics)
    theta_flat = []
    patient_ids = []
    
    for patient_id, idx in theta_results['patient_id_to_idx'].items():
        theta = theta_results['theta_temporal'][idx]
        # Flatten to 1D vector
        theta_flat.append(theta.flatten())
        patient_ids.append(patient_id)
    
    theta_flat = np.array(theta_flat)
    
    # Perform clustering
    kmeans = KMeans(n_clusters=n_clusters, random_state=42)
    clusters = kmeans.fit_predict(theta_flat)
    
    # Visualize with PCA
    pca = PCA(n_components=2)
    theta_2d = pca.fit_transform(theta_flat)
    
    plt.figure(figsize=(10, 8))
    for c in range(n_clusters):
        mask = clusters == c
        plt.scatter(theta_2d[mask, 0], theta_2d[mask, 1], 
                   label=f'Cluster {c}', alpha=0.6, s=100)
    
    plt.xlabel('PC1')
    plt.ylabel('PC2')
    plt.title('Patient Clusters Based on Disease Trajectories')
    plt.legend()
    plt.grid(True)
    plt.savefig('patient_clusters.png')
    plt.close()
    
    # Analyze cluster characteristics
    for c in range(n_clusters):
        mask = clusters == c
        cluster_patients = [patient_ids[i] for i, m in enumerate(mask) if m]
        print(f"\nCluster {c}: {sum(mask)} patients")
        print(f"  Example patients: {cluster_patients[:5]}")
        
        # Average theta for this cluster
        avg_theta = theta_flat[mask].mean(axis=0)
        avg_theta_reshaped = avg_theta.reshape(theta_results['theta_temporal'].shape[1:])
        
        # Find characteristic topics
        avg_across_time = avg_theta_reshaped.mean(axis=0)
        top_topics = np.argsort(avg_across_time)[-3:][::-1]
        print(f"  Characteristic topics: {top_topics}")
    
    return clusters, patient_ids

clusters, patient_ids = cluster_patient_trajectories(n_clusters=3)
```

**What this reveals**:
- Patient subtypes with similar disease trajectories
- Phenotypic groups for personalized treatment
- Heterogeneity in disease presentation and progression

## Understanding the Data Flow

1. **Input**: CSV files with medical codes (ICD, medications, procedures)
2. **Vocabulary Building**: String codes → Integer IDs
3. **Patient Processing**: Organize codes by patient and time
4. **Model Training**: Learn topic distributions that evolve over time
5. **Output**: 
   - Vocabularies (decode integer IDs)
   - Patient sequences (what codes each patient had when)
   - Theta temporal (what topics were active for each patient over time)
   - Mappings (connect patient IDs to array indices)

## File Dependencies

When loading data, you typically need:
- `vocabularies.pkl` - to decode integer word IDs to actual medical codes
- `patient_id_mapping.pkl` - to map patient IDs to array indices in theta
- `theta_results.pkl` OR `patient_sequences.pkl` - depending on your analysis

## Tips

1. **Always load vocabularies first** if you need to interpret word IDs
2. **Check patient_time_mask** before using theta values (0 = no data at that time step)
3. **Use patient_id_to_idx** when indexing into theta_temporal array
4. **Theta values sum to 1** across topics for each patient at each time step
5. **Time steps are sequential** - step 0 is first visit, step 1 is second visit, etc.
